# FEEDiT Landing

플랫폼과 별도로 배포할 수 있는 브랜드 소개 페이지입니다. 서비스 소개 자산으로 유지하며 `frontend/`의 번들에 들어가지 않는다는 이유로 삭제하지 않습니다.

진입점은 `index.html`입니다. 연결된 JS/CSS·영상·오디오·이미지와 vendored 라이브러리의 라이선스를 함께 유지합니다. 플랫폼 이동 링크를 바꿀 때는 스크립트의 실제 URL도 확인하세요.

Vercel에서 독립 프로젝트로 배포한다면 저장소 기준 Root Directory는 `landing`입니다. 플랫폼 본체의 `frontend` 설정과 혼용하지 않습니다. 로컬에서는 이 폴더를 정적 HTTP 서버로 제공합니다.

디자인은 패션 에디토리얼과 스크롤 모션을 중심으로 합니다. 사용 중인 자산은 코드 참조와 실제 화면 확인 후 교체합니다. [플랫폼 문서](../docs/README.md)
