# FEEDiT Showcase

브랜드의 인터랙티브 시각 경험을 보여주는 독립 정적 페이지입니다. 플랫폼 본체의 Vite 번들과 별도로 유지합니다.

`index.html`에서 연결하는 CSS·JavaScript·텍스처·오디오를 함께 제공합니다. 절차적 그래픽과 상호작용 모듈이 포함되므로 자산은 정적 문자열 검색뿐 아니라 브라우저 실행 경로를 확인한 후 제거해야 합니다.

Vercel 독립 프로젝트의 Root Directory는 `showcase`입니다. 로컬에서는 이 폴더를 정적 HTTP 서버로 제공합니다. 기존 오픈소스와 자산의 라이선스 표기를 보존합니다.
